How to use (for now)

There are two main functions, the main function inside of the editor folder and the main function inside of the main folder. The editor folder when you run it will open the editor panel that can be used to make levels.
The buttons at the button of the editor will change what behaviors the tiles you place (while the button option is enabled) will have. The visual difference is the same but it changes the properties behind the scenes.
To save the map it will be a .txt file and you need to have filled it out completely, then press s to open the save and make the new .txt file of whatever name you wish.
Please note that you need to press tab before any keyboard inputs can be recorded for now.

To use the other main function (the one located inside of the main folder) you need to go into the tile manager class and change the file path to be the file you wish to open to and then it will open that file.
